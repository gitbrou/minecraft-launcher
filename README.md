## 🛠️ Запуск проекта:

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Vite + Electron Live Reload)
npm run dev

# Компиляция TypeScript и сборка интерфейса
npm run compile

# Сборка финального Windows EXE дистрибутива (Onecompile / electron-builder)
npm run build
```
