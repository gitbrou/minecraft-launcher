## Скачать

Windows, macOS и Linux [установщик](https://github.com/gitbrou/minecraft-launcher/releases/latest).

## Использование

Ник, вресия, кнопка играть

## Сборка

```bash
npm install
npm run dev
```

## Данные

В `%APPDATA%\mine-launcher\.mine-launcher` лежат аккаунты, сборки, настройки, версии,
скины и миры.
